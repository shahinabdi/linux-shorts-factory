# Remotion production brief

Create a vertical 1080x1920 Persian Linux YouTube Short from the approved script.

- No narration / voice-over.
- Absolutely no background music.
- Sound effects only, subtle and purposeful, using licensed or original assets.
- Use screen recordings, terminal captures, UI footage, diagrams, animated typography and concise Persian RTL captions.
- Keep one idea per scene; ensure Persian text is legible on a phone.
- Do not invent UI states, command output, release information or benchmark results.
- For terminal demonstrations, use safe commands and show realistic output.
- Deliver MP4 plus title, description, tags, source references and a short fact-check note.
- Do not publish automatically; send the rendered file to Telegram for final human review.
